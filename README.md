# Interactive Quiz Application

A browser-based multiple-choice quiz built with HTML, CSS and JavaScript.

**Live demo:** YOUR_QUIZ_VERCEL_URL

## Features
- 8 questions on Python, web development and Git, shown one at a time
- Instant feedback: correct answer turns green, wrong answer turns red
- Live score and progress bar
- Final result with percentage, a message and a review of every question
- Restart button to try again
- Responsive on mobile and desktop

## Technologies
HTML, CSS, JavaScript (no libraries)

## How to run
1. Clone the repo: `git clone https://github.com/YOUR_GITHUB_USERNAME/interactive-quiz-application.git`
2. Open `index.html` in any browser

## How it works
Questions are stored as an array of objects (`q`, `o` options, `a` index of the correct answer) in `script.js`. To add a question, add one more object to that array.
